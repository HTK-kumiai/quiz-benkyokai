## 本番スクリプト (Naskah Lengkap)

### 1. 開演前 (Sebelum Mulai)

```
【客待ちの間、落ち着いたBGMを流す】

司会：「只今より、［イベント名］を開会いたします。
      皆様、お席にお着きください。」
```

**Penjelasan:** Sambil menunggu tamu, putar BGM. MC minta semua duduk dulu.

---

### 2. 自己紹介 & 開会宣言 (Perkenalan Diri)

```
司会：「お待たせいたしました。
      本日司会を務めさせていただきます、［名前］と申します。
      どうぞよろしくお願いいたします。」

司会：「それでは只今より、［イベント名］を始めさせていただきます。」
```

**Penjelasan:** Perkenalkan diri, lalu buka acara resmi.

---

### 3. 主催者挨拶 (Sambutan Penyelenggara)

```
司会：「それではまず初めに、主催者を代表致しまして、
      ［役職・名前］よりご挨拶を頂戴いたします。
      ［名前］様、よろしくお願いいたします。」

【主催者が話し終えた後】

司会：「［名前］様、ありがとうございました。」
```

**Penjelasan:** Panggilkan pembicara → selesai → ucapkan terima kasih.

---

### 4. 乾杯 (Cheers)

```
司会：「続きまして、乾杯の音頭を取っていただきます。
      ［来賓名］様、よろしくお願いいたします。」

【乾杯後】

司会：「ありがとうございます。それでは皆様、
      お食事とご歓談をお楽しみください。」
```

**Penjelasan:** Panggilkan yang ambil bagian di cheers → "selamat menikmati" → bebas ngobrol.

---

### 5. セグメント間の繋ぎ (Transisi Antar Segmen)

```
【余興に入る前】

司会：「お食事は進みましたでしょうか。
      ここからは、会場の雰囲気をさらに盛り上げるため、
      ○○をご用意しております。」

【余興後】

司会：「素晴らしい［出し物］でした。
      ［出演者名］の皆様かりましたを有り難うございます。」
```

**Penjelasan:** Penghubung halus antar segmen. Puji singkat setelahnya.

---

### 6. ゲーム / 抽選会 (Kalau Ada)

```
司会：「お楽しみの時間がやってまいりました。
      本日の［景品名］をご用意しております。
      ルールは…」

【終了後】

司会：「おめでとうございます！
      それでは続きを参りましょう。」
```

**Penjelasan:** Jelaskan aturan dengan jelas & semangat.

---

### 7. 閉会の挨拶 (Penutup)

```
司会：「あっという間のお時間でしたが、
      これを持ちまして［イベント名］を閉会とさせていただきます。
      皆様、本日は誠にありがとうございました。
      お忘れ物のないようお気をつけてお帰りください。
      ありがとうございました。」
```

**Penjelasan:** Ucapan penutup + salam perpisahan.

## 予備フレーズ (Kalimat Darurat)

Kalau ada **jeda awkward / teknis error / lupa**, pakai ini:

| 状況 | フレーズ |
|------|---------|
| Butuh jeda | 「只今、準備の時間を頂戴いたします」 |
| MC lupa | 「ここで一度、流れを振り返らせていただきます」 |
| 観客と交流 | 「皆様、お元気ですか？」 |
| 時間が押す | 「大変啦れ入りますが、この辺りで…」 |
| マイクの故障 | 「恐れ入りますが、拍手でお願いいたします」 |
| 写真を撮影 | 「皆的目光を一堂に頂戴いたします」 |
| 延長したい | 「もう少しだけ引っ張らせて顶戴いたします」 |

## 司会者の心得 (Tips Penting)

### やること ✅

- 話すスピードは **ゆっくりめ** (Jepang suka bicara santai)
- 名前を呼ぶ時は **はっきり** 発音する
- マイクは口元から **10cm** 離す
- 表情は **笑顔** を基本に
- アクシデントでも **冷静に** 対応

### やらないこと ❌

- 坛語を **早口** で読む
- 「えー」「あのー」过多 (hindari pengisi bingung berlebihan)
- 出演者の名前を **間違う**
- 手机を弄る (don't play with phone)
- 焦った表情を見せる

## カスタマイズ例

### 忘年会 / 新年会 用

```
司会：「本年度も残りわずか…
      今年的成果を労い，明年もさらなる飛躍を析りします。」
```

### 歓送会 / 歓迎会 用

```
司会：「［名前］様、長い間お疲れ様でした。
      新しい職場でもご活躍をお祈り申し上げます。」
```

### 卒制 / 入学 式 用

```
司会：「本日ここに、～年度入学式を開会いたします。
      新しい門出に掌声顶戴いたします。」
```
