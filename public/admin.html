Alur yang dipakai sekarang

1. Admin membuat akun di Supabase Auth. 2. Admin menandai profilnya sebagai is_admin = true. 3. User login dari halaman kuis memakai email + password. 4. Skor tersimpan ke tabel scores dan admin bisa melihatnya di tab Riwayat Skor.
